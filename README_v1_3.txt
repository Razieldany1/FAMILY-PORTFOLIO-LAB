FAMILY PORTFOLIO LAB v1.3 — CONFRONTO DUE PORTAFOGLI

1. Esporta il backup JSON prima dell'aggiornamento.
2. Sostituisci i file dell'app nel repository GitHub, preservando i dati locali.
3. Verifica il deployment Cloudflare e la pagina /; non cancellare cache o dati Android.
4. Nel Portfolio Builder salva almeno due portafogli per lo stesso figlio.
5. Scegli scenario e i due portafogli A/B.
