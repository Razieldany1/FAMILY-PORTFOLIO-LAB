FAMILY PORTFOLIO LAB v1.2 — Portfolio Builder

1. Esportare backup JSON prima di aggiornare.
2. Caricare i file nel repository GitHub, attendere il deploy Cloudflare.
3. Aprire Portfolio Builder e creare portafogli per Leo/Bianca.
4. I portafogli sono salvati nel backup JSON versione 1 (campo opzionale portfolios).
5. ISIN: verifica checksum e catalogo limitato, nessun recupero live.
6. Crisi: proxy ipotetici di categoria, NON rendimenti storici degli ETF.
7. Golden Butterfly: proxy grossolano, bond lunghi/brevi e fattori azionari non sono distinti nei rendimenti; non usarlo per giudizi di performance reali.
8. Il builder non modifica portafogli reali, PAC o dati di FAMILY CFO.
